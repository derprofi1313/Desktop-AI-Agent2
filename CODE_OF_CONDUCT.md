# Code of Conduct

## Our Standards

Contributors are expected to be respectful, constructive, and focused on the
work. Good participation includes:

- using welcoming and inclusive language;
- accepting technical feedback professionally;
- keeping disagreements about code, design, and security evidence-based;
- avoiding harassment, insults, personal attacks, and discriminatory language.

## Enforcement

Project maintainers may moderate issues, pull requests, discussions, and other
project spaces to keep participation productive. Unacceptable behavior may lead
to edited or removed comments, temporary limits, or removal from the project
community.

## Reporting

Report conduct concerns to the project maintainers through the repository's
private contact path when available. Security vulnerabilities should be reported
through GitHub private vulnerability reporting as described in `SECURITY.md`.
